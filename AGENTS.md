# Harness loop engineering

This repo is a copyable template for an agentic coding harness, plus lessons in
`examples/`. It is not application code, and it is not an IDE feature: the same
roles, verification, and enforcement should work under any tool through a thin
generated adapter.

Exit codes: 0 means pass. 1 means the code under test is wrong, so fix the
code. 2 means the harness is wrong (missing tool, bad or absent config), so
stop and report. Never retry a 2.

Run `scripts/verify.sh turn` before claiming any task complete. Do not hand
edit `.claude/` or `.cursor/`. Those files are generated by `adapters/render.sh`.

Content voice: flowing prose, no em dashes, no clipped fragments.

Procedures live in `skills/` and load on demand. Harness behaviour is configured
in one place: `harness.config.yaml`.
